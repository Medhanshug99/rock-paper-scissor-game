# 🎮 Rock Paper Scissor Game

An interactive **Rock–Paper–Scissors game** built using  
**HTML, CSS, and JavaScript**.

## 🚀 Features
- User vs Computer gameplay
- Live score tracking
- Win / Lose / Draw result display
- Reset game functionality
- Start Game button before play
- Responsive design
- Dark neon themed UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🎯 How to Play
1. Click the **Start Game** button.
2. Choose Rock, Paper, or Scissor.
3. The computer makes a random choice.
4. The result is displayed instantly.
5. Scores update automatically.
6. Click **Reset Game** to start over.
